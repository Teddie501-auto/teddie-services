# Fixed-Scope AI Cost Review — 25 USDC

A compact unit-economics review for one LLM-powered workflow. The goal is to identify whether pricing and usage assumptions are viable, and which single cost experiment is most worth running next.

## Deliverable

A public Markdown report in this repository containing:

- expected, heavy-user, and stress scenarios;
- model and non-model variable cost per successful run;
- monthly contribution margin at the supplied price and usage;
- break-even usage per customer;
- the three largest cost or margin risks;
- three prioritized optimization experiments;
- an assumptions table so the analysis is reproducible.

Where useful, the report also includes a small CSV of scenario outputs. This is analysis, not implementation, financial advice, or a guarantee of savings.

## Fixed scope

- One product, feature, or workflow
- Up to three model routes
- Up to three usage scenarios
- One clarification round before analysis
- One correction round for factual or arithmetic errors
- Delivery target: within 2 business days after matched payment and complete inputs
- Price: **25 USDC on Base**

Requests outside this scope require a separate quote. Do not send payment until scope is agreed in a GitHub issue and a payer-specific invoice is issued.

## Inputs required

Open an issue using the inquiry template and provide only approximate, non-sensitive aggregates:

- customer price and billing period;
- monthly successful runs per customer;
- model name/route and current public token prices;
- average input and output tokens per call;
- average calls per successful run;
- retry or failure rate;
- other variable API/infrastructure cost per run;
- target contribution or gross margin;
- payer's own Base wallet address, **only after** scope is accepted and an invoice is requested.

Never post prompts, customer data, credentials, private logs, confidential code, or personally identifying information. Exchange omnibus withdrawal addresses are unsuitable because payment cannot be reliably attributed.
